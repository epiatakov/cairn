# Clean-room statement

cairn is a personal open-source project. All code, documentation and example data in this
repository were written from scratch for this repository.

## What cairn is built from

Only publicly documented patterns and techniques, including:

- **`AGENTS.md`**: the open convention for agent instructions at a repository root.
- **Claude Code hooks, skills folders and `CLAUDE.md`**, as described in public documentation.
- **Markdown with frontmatter**, as used by static-site generators and note-taking tools.
- **Okapi BM25 / BM25F** ranking, from the published information-retrieval literature.
- **Shingling and Jaccard similarity** for near-duplicate detection, from the published literature.

## What cairn does not contain

- No code, configuration, prompts or documents copied from any employer, client or other
  non-public source.
- No employer names, internal product or project names, internal tool names, or internal file
  layouts.
- No real incident data. The example brain contains only generic, publicly known facts about
  common developer tools.

## For contributors

By contributing, you confirm that your contribution is your own original work, or is clearly
attributed and compatible with the MIT license, and that it follows the rules above. If you are
unsure whether something crosses the line, leave it out and open an issue to ask.
